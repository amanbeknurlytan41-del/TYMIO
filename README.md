# TYMIO

Инклюзивті IT оқу сайты. Жобаны VS Code-та осы папкадан ашыңыз.

## Іске қосу

Келесі жолы бүкіл сайт, 3D робот және AIVA бірден жұмыс істеуі үшін `start.cmd` файлын екі рет басыңыз: ол жергілікті серверді іске қосып, браузерді автоматты ашады. Сервер іске қосылып тұрса, браузерден `http://127.0.0.1:8787` мекенжайын ашыңыз.

Жалпы сұрақтарға жауап беретін AIVA үшін:

1. `.env` файлын ашыңыз (`.env.example` — үлгі).
2. `OPENAI_API_KEY=` жолына өз OpenAI API кілтіңізді енгізіңіз. Кілтті чатқа, HTML не JavaScript файлына жазбаңыз.
3. `start.cmd` файлын іске қосыңыз.
4. `http://127.0.0.1:8787` мекенжайын браузерде ашыңыз.

Кілт өзгерсе, сервер оны келесі сұрауда қайта оқиды. Әдепкі модель — `gpt-4.1-mini`; `OPENAI_MODEL` арқылы өзгертуге болады. API аккаунтында рұқсат пен жеткілікті лимит қажет.

## Негізгі мүмкіндіктер

- TYMIO ORBIT: жаңа 3D дизайн, бұрылатын CSS кубы, көлемді оқу аралдары мен ойын тақтасы.
- Қозғалысты өшіретін 2D режим; жүйенің reduced-motion таңдауы ескеріледі.
- Жеке оқу орталығы: соңғы модульді жалғастыру, нақты прогресс, XP және жетістіктер.
- Күнделікті есеп: күніне бір рет 25 XP (Asia/Qyzylorda күнімен).
- Тақырып бойынша жеке дәптер: браузерге сақтау және TXT ретінде жүктеу.

- Қазақша, орысша, ағылшынша интерфейс және түсіндірмелер.
- Python, JavaScript, HTML, CSS, Java, C++, C#, SQL: 8 бағыт, 16 кеңейтілген модуль.
- 32 тапсырма: себепті түсіндіру және код нәтижесін өздігінен есептеу. Бұл еркін код орындайтын орта емес.
- 8 деңгейлі алгоритм ойыны: 7×7 карта, кілт, есік, кристалл, энергия және блок лимиті, repeat командалары, қадамдық орындау.
- 8 авторлық дыбыссыз мәтіндік бейнесабақ, әрқайсысы қазақша/орысша/ағылшынша: 24 MP4, 24 VTT, тілдері бөлек таңдалады. Әр видео — 110 секунд.
- «Өз қарқының», «Ыңғайлы көрініс», «Дыбыссыз түсінікті» карточкалары оқу прогресін, баптауларды және видео бөлімін ашады.
- AIVA: AI қосылғанда ғылым, тарих, математика, мәтін жазу, күнделікті және программалау сұрақтары. Үш тіл, әңгіме контексті және сұрауды тоқтату бар.
- Үлкен мәтін, жоғары контраст, пернетақтамен басқару.
- Жергілікті видео және VTT субтитрлерін таңдау.
- Ым зертханасы: енгізілген толық сөйлемді сөздерге бөліп, барлық сөзді 3D робот қолының видео-таймлайнымен ретімен көрсетеді.
- Алға/артқа, жылдамдық, автоматты ойнату және әр сөздің әріптік көрінісі бар; дайын сөздерге адамға ұқсас қимыл беріледі.

## Деректер және шектеулер

Прогресс пен тіл таңдауы осы браузердің localStorage қоймасында сақталады.
Чат хабарламалары бет жадында сақталады, жаңартқанда өшеді. AI режимінде сұрақ пен соңғы контекст OpenAI қызметіне жіберіледі. Сервер чат мәтінін дискіге жазбайды. API сұрауында `store: false` қолданылады; бұл провайдердің барлық дерек өңдеу ережелерін алмастырмайды.
Видео файлдары серверге жүктелмейді.

AIVA жалпы сұрақтарға OpenAI Responses API арқылы жауап береді. Кілтсіз режимде тек дайын оқу материалдары қолжетімді, интерфейс мұны анық көрсетеді.

Сервер тек 127.0.0.1 мекенжайында жұмыс істейді және рұқсат етілген сайт файлдарын ғана береді. `.env` қосылған папканы қарапайым статикалық сервермен жарияламаңыз. Интернетке жариялау үшін авторизация мен серверлік құпия баптауы қажет.

AI тірі интернет іздеуін жасамайды, код орындамайды және қателесуі мүмкін. Тіл ауысқанда келесі AI жауабы жаңа тілде келеді; бұрынғы AI жауаптары өзгермейді.
Видео — авторлық мәтіндік слайд түсіндірмелері, дыбыссыз. Кәсіби ым тілі аудармасы әзірге қосылмаған.
